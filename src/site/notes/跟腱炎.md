# 跟腱炎（跟腱病）

> 足跟后方跟腱疼痛，跑步、跳跃、蹬地时加重，本质是跟腱的**肌腱病**而非急性发炎。

## 一、这是什么

「跟腱炎」的准确叫法是**跟腱病**（achilles tendinopathy）——跟腱在反复「储能—释放」负荷（跑跳、蹬地）下出现的负荷相关疼痛与功能下降。它不遵循三期炎症，因此「绝对休息 + 冰敷 + 抗炎药」不应作为终点治疗，核心是**渐进负荷**。

## 二、康复评估要点（来源：运动功能障碍）

- **受力归因**：跟腱痛来自腱体/止点的**牵伸力 + 储能释放负荷**，跑跳、蹬地时加重。
- **关键检查**：跟腱中段或止点（跟骨后方）压痛；提踵、单腿跳诱发疼痛；踝背伸受限是常见危险因素，一并评估。
- 追上游：小腿三头肌力量不足、踝背伸受限、跑量骤增是主要可干预诱因。

## 三、分阶段康复方案（来源：NSCA-CSCS 第22章 + 现代肌骨物理治疗 第10.2章）

### 肌腱病负荷连续体（来源：现代肌骨物理治疗 第10.2章）

1. **等长收缩减痛**（提踵等长）→ 2. **重慢阻力力量训练**（小腿三头肌 + 动力链）→ 3. **渐进引入速度** → 4. **能量储存负荷**（跑跳）。进阶由**负荷后 24 小时疼痛反应**引导，引入速度时留 3–4 天间隔。

### 按愈合阶段的可做/禁忌

| 阶段 | 可做 | 禁忌 |
|---|---|---|
| 炎症反应期 | 小腿无痛等长；健侧 + 髋/核心训练 | 患侧跑跳、反复蹬地 |
| 修复期 | 小腿三头肌向心+离心负荷；踝背伸活动度；动力链强化 | 深摩擦、重拉伸、过度负荷 |
| 成熟-重塑期 | 重慢阻力；逐步引入跑跳 | 过早爆发力、以「不痛」替代阶段目标 |

### 运动处方剂量（来源：现代肌骨物理治疗 第31章）

- 先运动控制后负荷；未训练 60% 1RM/周3天/4组，业余 80%/周2天/4组，运动员 85%/周2天/8组。

## 四、进阶与重返标准

- 阶段目标达成才进阶；重返跑步需力量与功能双侧差异 < 10%。
- 疼痛消失 ≠ 已愈合，须以客观测试放行。

## 五、红旗征（出现即转诊）

- 急性断裂（突感「被踢」、无法提踵）、局部红肿热痛（感染）、夜间痛。
