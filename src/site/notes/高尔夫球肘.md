# 高尔夫球肘（肱骨内上髁痛）

> 肘内侧痛，本质是腕屈肌-旋前肌群共同肌腱止点的**肌腱病**，是网球肘的「内侧镜像」。

## 一、这是什么

高尔夫球肘即肱骨内上髁痛（medial epicondylalgia），是腕屈肌群与旋前圆肌共同肌腱止点的负荷相关疼痛，常由反复屈腕、旋前、抓握（挥杆、投掷、提物）诱发。与网球肘同理，多数属于肌腱病而非急性炎症。

## 二、康复评估要点（来源：运动功能障碍）

- **受力归因**：抗阻屈腕/旋前诱发内侧痛是**牵伸力**；抓握提物是**压缩 + 牵伸**叠加。
- **关键检查**：抗阻屈腕/旋前疼痛再现 + 内上髁远端压痛。
- 追上游：肩胛与躯干动力链无力同样会迫使前臂代偿，需一并评估。
- 注意鉴别：肘内侧痛须排除尺神经病变（环小指麻木）——若合并神经症状，先转诊评估。

## 三、分阶段康复方案（来源：NSCA-CSCS 第22章 + 现代肌骨物理治疗 第10.2章）

### 肌腱病负荷连续体（来源：现代肌骨物理治疗 第10.2章）

1. **等长收缩减痛** → 2. **重慢阻力力量训练**（腕屈肌-旋前肌群 + 握力 + 动力链）→ 3. **渐进引入速度** → 4. **能量储存负荷**（挥杆/投掷爆发动作）。进阶由**负荷后 24 小时疼痛反应**引导。

### 按愈合阶段的可做/禁忌

| 阶段 | 可做 | 禁忌 |
|---|---|---|
| 炎症反应期 | 无痛屈腕/旋前等长；肩胛/躯干训练；健侧训练 | 患侧反复屈腕、旋前、抓握 |
| 修复期 | 屈肌-旋前肌群向心+离心负荷；握力渐进；动力链强化 | 深摩擦、重拉伸、诱发剧痛的动作 |
| 成熟-重塑期 | 重慢阻力；逐步引入速度与挥杆动作 | 过早爆发力、以「不痛」替代阶段目标 |

### 运动处方剂量（来源：现代肌骨物理治疗 第31章）

- 先运动控制后负荷；未训练 60% 1RM/周3天/4组，业余 80%/周2天/4组，运动员 85%/周2天/8组。

## 四、进阶与重返标准

- 阶段目标达成才进阶；重返握持/挥杆运动需力量与功能双侧差异 < 10%。
- 疼痛消失 ≠ 已愈合：须以客观肌力/功能测试放行。

## 五、红旗征（出现即转诊）

- 尺神经支配区麻木无力、进行性无力、发热、疑似骨折/感染。
