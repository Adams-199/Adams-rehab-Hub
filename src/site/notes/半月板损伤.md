# 半月板损伤

> 膝关节内侧或外侧半月板在扭转负重下撕裂，表现为关节线压痛、深屈曲/扭转痛，重者可「绞锁」。

## 一、这是什么

半月板是膝关节内外的「垫片」，起缓冲、稳定与分散负荷作用。损伤多由负重位扭转（急停变向、深蹲旋转）引起，分保守可愈（血供较好的边缘撕裂）与需手术（桶柄状撕裂绞锁）两类。物理治疗目标不是「长回半月板」，而是控制负荷、恢复活动度与肌力、避免绞锁动作。

## 二、康复评估要点（来源：运动功能障碍 + 膝关节功能障碍）

- **受力归因**：半月板痛来自扭转/深屈曲时的**剪切力 + 压缩力**。
- **关键检查**：关节线压痛、McMurray 试验、深屈曲诱发痛；**绞锁/打软腿**提示机械性阻挡，须转手术判断。
- 桥本贵幸《膝关节功能障碍》特别提示：深屈曲时腘窝疼、半月板损伤保守治疗或部分切除术后仍有疼痛与活动受限者，须排查半月板（含腘肌）与后方结构的疼痛来源，而不仅是「半月板本身」。

## 三、分阶段康复方案（来源：NSCA-CSCS 第22章 + 现代肌骨物理治疗 第31章）

| 阶段 | 可做 | 禁忌 |
|---|---|---|
| 炎症反应期 | 无痛股四头肌等长；健侧 + 髋/核心训练；消肿（冰敷/抬高） | 患膝负重扭转、深屈曲、绞锁动作 |
| 修复期 | 多角度股四头肌等长 → 等张；腘绳肌/臀肌强化；活动度维持 | 深屈曲加压、旋转负荷、跑跳 |
| 成熟-重塑期 | 渐进抗阻；逐步恢复下蹲、变向、专项动作 | 过早爆发力、以「不痛」替代阶段目标 |

### 运动处方剂量（来源：现代肌骨物理治疗 第31章）

- 先运动控制（股四头肌激活、膝关节稳定）后负荷；未训练 60% 1RM/周3天/4组，业余 80%/周2天/4组，运动员 85%/周2天/8组。

## 四、进阶与重返标准

- 阶段目标（活动度/肌力/功能）达成才进阶；重返运动需力量与功能双侧差异 < 10% + 无绞锁/打软腿。

## 五、红旗征（出现即转诊）

- **关节绞锁**（桶柄状撕裂）、明显关节线压痛伴打软腿、进行性肿胀、夜间痛、疑似骨折/感染。
