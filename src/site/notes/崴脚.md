# 崴脚（踝关节外侧韧带扭伤）

> 足内翻位扭伤，最常见伤及距腓前韧带；康复目标是消肿止痛后重建踝关节动态稳定、防反复崴脚。

## 一、这是什么

崴脚即踝关节扭伤，以**外侧韧带损伤**（距腓前韧带 ATFL 最常见）为主，由足内翻 + 跖屈的扭转暴力引起。韧带属**静态稳定结构**，物理治疗改变不了它本身，应转向强化有制动作用的**动态稳定结构**（腓骨肌群、足内在肌）与本体感觉，这是「防再崴脚」的核心。

## 二、康复评估要点（来源：运动功能障碍）

- **受力归因**：内翻扭伤的疼痛来自外侧韧带的**牵伸力**。
- **关键检查**：前抽屉试验、距骨倾斜试验 + 与健侧对比；结合腓骨肌群肌力与单腿平衡评估。
- 静态结构已破坏时，不要用阴性试验否定诊断；症状部位（前外侧）决定责任韧带。

## 三、分阶段康复方案（来源：NSCA-CSCS 第22章 + 现代肌骨物理治疗 第31章）

| 阶段 | 可做 | 禁忌 |
|---|---|---|
| 炎症反应期 | 无痛等长；健侧 + 髋/核心训练；冰敷/加压/抬高 | 患踝负重、内翻、跑跳 |
| 修复期 | 多角度等长 → 腓骨肌/小腿等张；平衡与本体感觉（单腿站、闭眼） | 内翻应力、过早跑跳 |
| 成熟-重塑期 | 渐进抗阻；逐步恢复跳跃、变向；专项动作 | 过早爆发力、以「不痛」替代阶段目标 |

### 四级递进（来源：NSCA-CSCS 第22章）

活动度与肌力 → 肌耐力/力量 → 爆发力 → 专项速度；踝扭伤的篮球后卫「从一般性单关节练习进阶至与专项和位置更有关的练习」。

### 运动处方剂量（来源：现代肌骨物理治疗 第31章）

- 先运动控制后负荷；未训练 60% 1RM/周3天/4组，业余 80%/周2天/4组，运动员 85%/周2天/8组。

## 四、进阶与重返标准 + 再损伤预防

- 阶段目标达成才进阶；重返运动需力量与功能双侧差异 < 10%。
- 再损伤预防（来源：NSCA-CSCS 第22章）：**平衡训练、跳跃/落地神经肌肉控制、单腿深蹲**，是防反复崴脚的关键。

## 五、红旗征（出现即转诊）

- Ottawa 踝规则（外踝尖/第 5 跖骨基底部压痛、无法负重 4 步）提示需拍片；明显畸形、进行性肿胀。
