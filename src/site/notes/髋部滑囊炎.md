# 髋部滑囊炎（大转子滑囊炎）

> 髋外侧大转子周围痛，常见于侧卧压痛点，本质常与**臀肌腱病**相伴，属负荷相关疼痛。

## 一、这是什么

髋部滑囊炎以**大转子滑囊炎**（greater trochanteric bursitis）最常见，表现为髋外侧大转子区的疼痛与压痛，侧卧、久站、上下楼、跑步时加重。现代观点认为：**孤立的滑囊炎少见，大转子痛常是臀中肌/臀小肌腱病的一部分**，应按负荷管理处理，而非只打「消炎」的封闭。

## 二、康复评估要点（来源：运动功能障碍）

- **受力归因**：大转子区疼痛常来自内收位/侧卧时的**压缩力 + 摩擦/牵伸力**叠加。
- **关键检查**：大转子压痛 + 抗阻髋外展诱发症状；单腿站立（Trendelenburg 征）评估臀中肌控制；疼痛再现验证受力。
- 追上游：臀中肌无力是核心上游原因，须一并评估并纠正。

## 三、分阶段康复方案（来源：NSCA-CSCS 第22章 + 现代肌骨物理治疗 第10.2章）

### 负荷管理连续体（来源：现代肌骨物理治疗 第10.2章）

1. **等长收缩减痛**（臀肌无痛等长）→ 2. **重慢阻力力量训练**（臀中肌/臀大肌 + 动力链）→ 3. **渐进引入速度** → 4. **能量储存负荷**（跑跳）。进阶由**负荷后 24 小时疼痛反应**引导。
- 书中特别提示：髋周（内收位）是压缩性止点问题，**减少内收位/压缩位激发负荷，避免重拉伸**。

### 按愈合阶段的可做/禁忌

| 阶段 | 可做 | 禁忌 |
|---|---|---|
| 炎症反应期 | 臀肌无痛等长；核心与健侧训练 | 患侧内收位加压、侧卧压痛点持续受压 |
| 修复期 | 臀外展/外旋渐进等张；单腿控制 | 深摩擦、重拉伸、过度负荷 |
| 成熟-重塑期 | 重慢阻力；逐步引入跑跳 | 过早爆发力、以「不痛」替代阶段目标 |

### 运动处方剂量（来源：现代肌骨物理治疗 第31章）

- 先运动控制后负荷；未训练 60% 1RM/周3天/4组，业余 80%/周2天/4组，运动员 85%/周2天/8组。

## 四、进阶与重返标准

- 阶段目标达成才进阶；重返跑步需力量与功能双侧差异 < 10%。

## 五、红旗征（出现即转诊）

- 局部红肿热痛（感染）、发热、无法负重、疑似骨折。
