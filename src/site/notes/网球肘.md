# 网球肘（肱骨外上髁痛）

> 肘外侧痛，本质是腕伸肌群（尤其桡侧腕短伸肌）止点的**肌腱病**，而非单纯「发炎」。

## 一、这是什么

网球肘即肱骨外上髁痛（lateral epicondylalgia），是腕伸肌群共同肌腱止点的负荷相关疼痛。长期抓握、伸腕、拧毛巾等动作反复牵伸该肌腱而致病。多数属于肌腱病（退行/变性改变），不是急性炎症，因此「单纯休息 + 消炎」常不解决根本问题。

## 二、康复评估要点（来源：运动功能障碍）

- **受力归因**：把「痛」翻译成力——抗阻伸腕/伸中指是**牵伸力**，抓握提重物是**压缩 + 牵伸**叠加。
- **关键检查**：抗阻伸腕（尤其伸中指）诱发肘外侧疼痛、肱骨外上髁远端压痛，用疼痛再现验证。
- 追上游：肩胛与躯干动力链无力会迫使前臂代偿，是常见上游原因，需一并评估。

## 三、分阶段康复方案（来源：NSCA-CSCS 第22章 + 现代肌骨物理治疗 第10.2章）

### 肌腱病负荷连续体（来源：现代肌骨物理治疗 第10.2章）

1. **等长收缩减痛**（如握拳等长）→ 2. **重慢阻力力量训练**（腕伸肌群 + 握力 + 肩胛动力链）→ 3. **渐进引入速度** → 4. **能量储存负荷**（挥拍等爆发动作）。进阶由**负荷后 24 小时疼痛反应**引导。

### 按愈合阶段的可做/禁忌

| 阶段 | 可做 | 禁忌 |
|---|---|---|
| 炎症反应期 | 无痛腕伸肌等长；肩胛/躯干训练；健侧训练 | 患侧反复抓握、拧转、抗阻伸腕 |
| 修复期 | 伸腕肌群向心+离心负荷；握力渐进；动力链强化 | 深摩擦、重拉伸、诱发剧痛的动作 |
| 成熟-重塑期 | 重慢阻力；逐步引入速度与挥拍动作 | 过早爆发力、以「不痛」替代阶段目标 |

### 运动处方剂量（来源：现代肌骨物理治疗 第31章）

- 先运动控制后负荷；未训练 60% 1RM/周3天/4组，业余 80%/周2天/4组，运动员 85%/周2天/8组。
- 不以「绝对休息 + 冰敷 + 抗炎药」为终点治疗。

## 四、进阶与重返标准

- 阶段目标达成才进阶；重返握持/挥拍运动需力量与功能双侧差异 < 10%。
- 疼痛消失 ≠ 已愈合：须以客观肌力/功能测试放行。

## 五、红旗征（出现即转诊）

- 进行性无力（需排除神经卡压）、肘关节交锁、发热、疑似骨折/感染。
